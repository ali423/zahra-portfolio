# پورتفولیوی زهرا گودرزی‌راد

سایت دوزبانه با Next.js ساخته شده است. خروجی نهایی HTML ایستا است و به بک‌اند، کلید API یا پایگاه داده نیاز ندارد.

## اجرا روی کامپیوتر

در این پوشه با Node.js نسخهٔ ۲۲ یا جدیدتر، دستورهای زیر را اجرا کنید.

```sh
npm ci
npm run dev
```

پیش‌نمایش توسعه در http://localhost:3000 باز می‌شود. برای بررسی خروجی نهایی از `npm run build` و سپس `npm start` استفاده کنید. دستور دوم به Python 3 نیاز دارد و محتویات پوشهٔ `out` را نمایش می‌دهد.

## انتشار روی Vercel

همین پوشهٔ حاوی package.json را در مخزن قرار دهید. مخزن را در Vercel وارد کنید و در صورت استفاده از مخزن بزرگ‌تر، Root Directory را روی پوشهٔ پروژه تنظیم کنید. تنظیمات Next.js و دستور ساخت `npm run build` کافی است. پس از انتشار، دامنهٔ `zahragoudarzi.ir` را در Settings → Domains اضافه کنید و رکورد DNS اعلام‌شده از سوی Vercel را نزد ثبت‌کنندهٔ دامنه وارد کنید.

## محتوا و بازبینی

- آثار، شرح فنی، مدارک و سوابق کاری در `lib/content.ts` هستند. متن آغاز صفحه، ترتیب آثار و تصاویر هر اثر در `lib/studio.ts` تنظیم می‌شوند.
- صفحه با پرتره و معرفی زهرا آغاز می‌شود. با اسکرول، بسته‌بندی حلقه‌ای آرامیس و ۲۲ مجموعهٔ دیگر دیده می‌شوند. نقاشی و تصویرسازی با دکمهٔ انتهای همان صفحه باز می‌شود.
- نسخه‌های نمایشی تصاویر محصول و عکس‌های کارگاهی در `public/images/editions` و تصاویر اصلی و برگه‌های پروژه در `public/images` هستند. فونت‌های سایت از `public/fonts` بارگیری می‌شوند.
- دو PDF قابل دریافت در `public/documents` هستند. برای به‌روزرسانی رزومه، فایل `resume.pdf` را جایگزین کنید.
- موارد نیازمند بازبینی در یادداشت پروژه‌ها و بخش سوابق با زرد مشخص شده‌اند. پس از تأیید اطلاعات، نشانهٔ `mark` یا پرچم `review` متن مربوط را بردارید.
- نام دانشگاه بر مبنای دو رزومه «دانشگاه هنر تهران» درج شده است. نام آزمون زبان، نمره و شمارهٔ گواهی در منابع ارسالی ذکر نشده‌اند.
- انتخاب زبان و حالت نمایش در مرورگر ذخیره می‌شود. لینک `/?lang=en` نسخهٔ انگلیسی را باز می‌کند.
